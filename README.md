## 🚀 Projeto em destaque

### 💼 Ingrid CRM

Sistema Full Stack para gerenciamento de clientes e leads, com dashboard e operações CRUD completas.

**Principais funcionalidades:**

- Cadastro de clientes
- Listagem de registros
- Edição de clientes
- Exclusão de clientes
- Controle de status
- Dashboard com indicadores
- Integração com PostgreSQL
- API REST

**Tecnologias:**

`React` `JavaScript` `Node.js` `Express` `PostgreSQL` `CSS` `Git`

👉 [Ver projeto Ingrid CRM](https://github.com/Ingridsoftwareprograma/ingrid-crm)
