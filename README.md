## 👩‍💻 Sobre mim

Sou estudante de **Tecnologia da Informação** e estou construindo minha trajetória na área de desenvolvimento de software.

Gosto especialmente de transformar uma ideia em algo que realmente funcione: pensar na interface, estruturar as informações, desenvolver as funcionalidades, conectar o Front-end ao Back-end e ver os dados sendo armazenados e utilizados pela aplicação.

Tenho me dedicado ao desenvolvimento **Full Stack**, trabalhando com tecnologias como **React, JavaScript, Node.js, Express e PostgreSQL**, além de continuar evoluindo meus conhecimentos em **Python**.

Também estou aprofundando meus estudos em **Inteligência Artificial**, buscando entender como IA pode ser utilizada junto ao desenvolvimento de software para criar aplicações mais inteligentes, automatizar processos, apoiar análise de dados e resolver problemas de formas diferentes.

Mais do que aprender uma ferramenta específica, gosto de entender **como as tecnologias podem trabalhar juntas para transformar um problema em uma solução**.

## 🚀 Projeto em destaque

### 💼 Ingrid CRM

Sistema Full Stack para gerenciamento de clientes e leads.

O projeto nasceu da ideia de desenvolver uma aplicação completa, trabalhando diferentes partes de um sistema real.

Atualmente possui:

- 👥 Cadastro de clientes
- 📋 Listagem de registros
- ✏️ Edição de clientes
- 🗑️ Exclusão com confirmação
- 📌 Gerenciamento de status
- 📊 Dashboard de acompanhamento
- 🔄 Integração Front-end e Back-end
- 🗄️ Persistência de dados com PostgreSQL
- 🔗 API REST

### Tecnologias utilizadas

`React` • `JavaScript` • `Node.js` • `Express` • `PostgreSQL` • `CSS` • `Git`
