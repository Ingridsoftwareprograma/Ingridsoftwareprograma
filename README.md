## 🚀 Projeto em destaque

### 💼 Ingrid CRM

Sistema **Full Stack** para gerenciamento de clientes e leads, desenvolvido para colocar em prática diferentes conceitos de desenvolvimento de software.

O projeto integra **Front-end, Back-end, API REST e banco de dados PostgreSQL** em uma única aplicação.

### ✨ Funcionalidades

- 👥 Cadastro de clientes e leads
- 📋 Listagem de registros
- ✏️ Edição de informações
- 🗑️ Exclusão de clientes
- 📌 Gerenciamento de status
- 📊 Dashboard de acompanhamento
- 🔄 Integração entre Front-end e Back-end
- 🗄️ Persistência de dados com PostgreSQL
- 🔗 API REST

### 🛠️ Tecnologias utilizadas

`React` • `JavaScript` • `Node.js` • `Express` • `PostgreSQL` • `CSS` • `Git`
